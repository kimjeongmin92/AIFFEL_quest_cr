# 임베딩 내 편향성 알아보기: WEAT를 활용한 영화 장르 편향성 분석

## 프로젝트 개요

본 프로젝트는 영화 시놉시스 데이터를 기반으로 직접 Word2Vec 임베딩 모델을 학습하고, WEAT score를 이용하여 영화 장르별 예술영화/일반영화 편향성을 측정하는 것을 목표로 한다.

## 진행 과정

1. 영화 시놉시스 데이터 로드
2. Okt 형태소 분석기를 이용한 명사 추출
3. Word2Vec 임베딩 모델 학습
4. most_similar()를 통한 임베딩 품질 확인
5. TF-IDF를 이용한 장르별 대표 단어 추출
6. 예술영화/일반영화 대표 단어 셋 생성
7. WEAT score 계산
8. 결과 시각화 및 해석

## 주요 결과

직접 학습한 Word2Vec 모델을 이용하여 영화 장르별 WEAT score를 계산하였다.

WEAT score가 양수인 장르는 예술영화 단어 셋과 상대적으로 더 가까운 경향을 보이며, 음수인 장르는 일반영화 단어 셋과 상대적으로 더 가까운 경향을 보인다고 해석하였다.

실험 결과 판타지, 애니메이션, 가족, 멜로로맨스 등은 예술영화 단어 셋과 상대적으로 가까운 경향을 보였고, 다큐멘터리, 기타, 전쟁, 액션 등은 일반영화 단어 셋과 상대적으로 가까운 경향을 보였다.

## 어려웠던 점과 해결 과정

실습 중 커널 재시작으로 인해 `okt`, `gensim`, `genre_name`, `tfidf_matrix` 등의 변수가 사라지는 문제가 발생하였다.

이 문제는 필요한 라이브러리와 변수를 다시 import하고, 사라진 TF-IDF 계산 결과와 장르별 대표 단어를 복구하는 방식으로 해결하였다.

또한 TF-IDF 점수가 높은 단어를 그대로 사용할 경우 여러 장르에서 공통적으로 등장하는 단어가 중복 선택될 수 있었다.

이를 해결하기 위해 불용어와 한 글자 단어를 제거하고, 이미 다른 장르에서 선택된 단어는 제외하는 방식으로 중복을 줄였다.

## 회고

이번 프로젝트를 통해 워드 임베딩이 단어의 의미뿐 아니라 데이터 안에 존재하는 관계와 편향성도 함께 학습할 수 있다는 점을 확인하였다.

WEAT score는 수치가 크다고 해서 무조건 사회적 차별을 의미하는 것이 아니라, 데이터 안에서 특정 개념들이 상대적으로 더 가깝게 사용되었다는 것을 의미한다.

따라서 결과를 해석할 때는 코퍼스의 특성, 형태소 분석 기준, 대표 단어 선정 방식의 한계를 함께 고려해야 한다.

추후에는 명사뿐 아니라 형용사와 동사까지 포함하여 영화의 감정과 분위기 정보를 더 반영하고, 대표 단어 선정 방식을 개선해 더 안정적인 WEAT score를 계산해보고 싶다.
