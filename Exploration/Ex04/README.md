# 네이버 영화리뷰 감성분석 도전하기

## 프로젝트 개요

NSMC 네이버 영화리뷰 데이터를 활용하여 한국어 감성분석을 수행하였다.  
영화 리뷰 문장을 입력으로 받아 긍정 또는 부정 감성을 예측하는 이진 분류 문제로 접근하였다.

## 전처리

- NSMC 데이터 다운로드 및 불러오기
- 중복 리뷰 및 결측치 제거
- Mecab 설치 오류로 인해 Okt 형태소 분석기 사용
- 불용어 제거
- 단어 사전 구성
- 정수 인코딩
- 문장 길이 분석 및 패딩 적용
- PyTorch DataLoader 구성

## 모델 실험 결과

| 모델 | Test Loss | Test Accuracy |
|---|---:|---:|
| 1-D CNN | 0.4618 | 0.8211 |
| GlobalMaxPooling | 0.4149 | 0.8068 |
| LSTM | 0.3747 | 0.8347 |
| LSTM V2 | 0.4068 | 0.8354 |

가장 높은 성능을 보인 모델은 LSTM V2이며, Test Accuracy는 0.8354였다.  
평가 기준인 85%에는 도달하지 못했지만, 총 4가지 모델을 실험하며 모델 구조별 성능 차이를 비교하였다.

## Word2Vec 적용 여부

과제에서 요구한 `word2vec_ko.model` 파일을 확인했으나 현재 실습 환경에서는 찾을 수 없었다.  
따라서 사전학습 Word2Vec 임베딩을 직접 적용하지 못했고, LSTM V2 모델의 자체 학습 Embedding 층을 분석하였다.

## 회고

이번 프로젝트를 통해 한국어 텍스트 감성분석의 전체 흐름을 경험하였다.  
한국어는 조사, 어미, 띄어쓰기 문제가 있기 때문에 형태소 분석 과정이 중요하다는 점을 확인하였다.  
추후에는 Mecab 환경을 정상화하고, 한국어 Word2Vec 사전학습 임베딩을 적용하여 성능 개선을 시도하고 싶다.
